# Personal Voice Skill

An AI-powered writing assistant that learns a user's unique writing style from LinkedIn posts, articles, blogs, emails, and other writing samples, then generates new content that matches their voice.

## Features

* Upload writing samples (PDF, TXT, or pasted text)
* Build a personalized voice profile
* Generate LinkedIn posts, blogs, emails, and social content in the user's style
* Retrieve relevant writing examples using semantic search
* Evaluate generated content for voice consistency

## Tech Stack

* Next.js 15
* TypeScript
* Tailwind CSS
* Supabase (Auth, Database, Storage, pgvector)
* Google Gemini API
* Vercel

## Key AI Concepts

* Retrieval-Augmented Generation (RAG)
* Embeddings & Semantic Search
* AI Personalization
* Prompt Engineering
* LLM-as-a-Judge Evaluation

## Purpose

Built to explore how AI can capture and replicate an individual's writing style while maintaining authenticity and consistency across different content formats.
